# Leilão Pokémon

Sistema para gerenciar leilões de cartas Pokémon integrados ao WhatsApp, com painel administrativo, histórico auditável, banco no Supabase e exportação para Excel.

> Projeto em fase inicial. A primeira entrega estabelece o domínio, o painel e a base segura do banco; a integração real com WhatsApp/Baileys será validada separadamente antes de uso em leilões reais.
